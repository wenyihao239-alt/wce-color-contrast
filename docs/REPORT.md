# 无线胶囊内镜色彩校正与保色细节增强：可执行预实验报告

**日期**：2026-11-03  
**硬件**：NVIDIA RTX 4060 Ti (16 GB)，i7-13700，32 GB RAM  
**数据集**：SEE-AI / PillCam SB3（18,481 帧；23,033 个病灶框）  
**代码与结果**：`C:\wce\wce_experiment`

## 0. 结论摘要

- CCC 校正在本数据上**几乎没有红通道硬截断**（潜在截断率 0.000%，实际 R≥254 占 0.0003%），因此 **H1a（截断效应）不成立**。
- CCC 校正是**gamma 空间仿射变换**（含大幅正偏移，行和 <1），其对比度损失来自**平滑的明度压缩**，而不是高频细节衰减：G3 中 A=0.0746 → M1=0.0282，而 M2=0.0742，说明色度几乎不贡献 L* 对比度。
- G2 未支持“红通道稀释绿通道血红蛋白梯度”：等效亮度权重变为 R=-0.94、G=2.27、B=-0.33（归一化），G/L 梯度比仅从 0.903 变为 0.893，但 G 与 L 的绝对梯度同时下降约 30%，是全局对比压缩。
- 截止尺度扫描的 P0 前沿近似**平坦**（ΔE00 0.48–0.55，病灶-周环对比度 0.026 左右），证明“细节层迁移”无法恢复 CCC 的平滑明度压缩；因此 P2 需要约 24× 的细节增益才能达到 E 的全黏膜 RMS 对比度——这是方法效率上的关键负面证据。
- 检测端（20 epochs、单 seed、初步）：AP50 最高为 **M1 = 0.291**；P0/E 的 F1 较高但 FP 也最多（P0=376，E=401），呈现“对比度增强提升召回但抬高假阳性”的权衡。
- 提出方法 **P2 vs E**：F1 0.339 vs 0.328，AP50 0.283 vs 0.278，FP 366 vs 401（Holm p=0.19，不显著），框面积比 0.981 vs 1.002；方向上 P2 略优，但糜烂/息肉样 FP 反而更高，属于混合证据。
- 由于 4060 Ti 的算力限制，本报告是**20 epochs 单 seed 的初步实验**，并非方案原定的 200/400 epochs × 3 seeds；所有条件使用同一训练预算，因此条件间相对比较仍有效，但绝对指标显著低于原论文。

## 2. CCC 变换的反推与验证

仓库未包含 CCM 代码，因此用 10,922 对 OrigD↔CCCD 图像在 gamma 空间拟合 3×3 仿射变换：

```
[+0.2732  +0.3626  -0.0707]
[-0.7361  +1.5802  -0.3176]
[-0.5075  +0.1595  +0.8942]
b = [+91.565, +73.629, +84.572]
```
- 分块均值拟合 RMSE = **1.685** /255；独立图像验证：与官方 CCC 图的中位 ΔE00 = **0.76**，MAE≈2。
- 行和（含偏移/255）：[0.924, 0.815, 0.878]，均 <1，说明是**降低对比度的仿射色调映射**。

## 3. 零成本闸门 G1–G3

### G1 红通道截断

- 有效黏膜像素 1,086,782,006；潜在任意通道截断 **0.0007%**，潜在 R 截断 **0.0000%**。
- 官方 CCC 图中实际任意通道 ≥254 占 **0.0017%**，R≥254 占 **0.0003%**。
- 判定：p_clip ≪ 1%，按方案**跳过 M3 的 3 次独立训练**，以 C 作为 M3 的近似；H1a 在本数据上不成立。

### G2 等效亮度权重与绿通道梯度

- CCC 等效线性组合权重（归一化）= [-0.942, 2.273, -0.331]（原 luma 权重 [0.213, 0.715, 0.072]）。
- CC 权重（归一化）= [-0.563, 1.78, -0.217]。
- 病灶框边界 G/L* 梯度比：A = 0.903，C = 0.893（几乎不变）。
- 绝对梯度：G 0.0590→0.0415，L* 0.0657→0.0470（同步下降约 30%）。
- 判定：**不支持**“红通道散射基底稀释绿通道血红蛋白梯度”的表述；对比度下降是全局性的。

### G3 图像层 2×2 析因（22,689 个有效框）

| 条件 | Michelson 病灶-周环对比度 | 相对 A |
|---|---:|---:|
| A | 0.0746 | 100.0% |
| M1 | 0.0282 | 37.8% |
| M2 | 0.0742 | 99.6% |
| M3 | 0.0282 | 37.8% |
| C | 0.0319 | 42.8% |

- **明度因子是主因**：M1（仅 CCC 明度）与 M3 均为 0.0282，而 M2（仅 CCC 色度）保持 0.0742，接近 A。

## 5. 训练协议

- 受控实验：YOLOv5s，img 576，batch 32，20 epochs，**关闭 mosaic / HSV 颜色增强 / mixup**，保留水平+垂直翻转与平移缩放；单 seed=42。
- 先验锚点（Priority 0）：官方 split + 官方增强（mosaic/HSV 开），20 epochs，seed=42。
| 锚点 | mAP50 | mAP50-95 |
|---|---:|---:|
| A_origd_s42 | 0.477 | 0.302 |
| C_cccd_s42 | 0.431 | 0.261 |

> 原论文 400 epochs 报告 YOLOv5 AP≈0.674；本机 20 epochs 锚点 mAP50≈0.43–0.48，绝对值不可直接对比，但 A≥C 的方向与原文一致。

## 8. 假设判读

| 假设 | 结果 | 证据 |
|---|---|---|
| H1a 通道硬截断导致副作用 | **不成立/可忽略** | G1：R 截断 0.0003%；C≈M3（ΔE≈0.8）。 |
| H1b 多尺度明度细节衰减 | **方向成立、机制修正** | G3：M1=M3=0.0282 vs A=0.0746；但扫描显示是平滑明度压缩，而非高频细节丢失，P0 无法恢复。 |
| H2 红色色度扩张独立增加 FP | **部分支持（单 seed）** | M2 的 FP=292、红斑 FROC=0.415，均高于 M1（FP=152、FROC=0.311）；但红斑绝对检测太弱。 |
| 提出方法 P2 优于 E | **弱/混合支持** | P2 的 F1/AP50 略高、FP 与框膨胀略低（FP 差异 Holm p=0.19 不显著），但糜烂/息肉样 FP 更高；且需 24× 细节增益，效率低。 |

## 9. 局限性

- **训练预算**：20 epochs、单 seed；原方案要求 200/400 epochs × 3 seeds。绝对 mAP/F1 明显偏低，红斑/出血等稀有类欠拟合。
- 4060 Ti 实测约 4–5 min/epoch；26 次训练在单卡上需约 25 h，本报告按用户选择的轻量方案执行。
- CCC 矩阵是从图像对反推的 gamma 空间仿射近似，非原仓库代码；中位 ΔE00=0.76，但仍可能有 ±1 的误差。
- 正常帧用 `theBG.jpeg` 掩膜匹配得到，与官方 OrigD 的 JPEG 域存在轻微差异。
- 单 seed 无法做跨 seed 聚合 Wilcoxon；当前统计为逐图像配对检验，结论应视为 preliminary。
