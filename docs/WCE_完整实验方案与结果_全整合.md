## 0. 版本演进与结论摘要

| 版本 | 条件 | 数据 | 训练 | 目的 | 证据地位 |
|---|---|---|---|---|---|
| V1 | A/C/M1/M2/M3/P0/P2/E | 官方 OrigD / CCCD JPEG | 20 epochs，单 seed | 2×2 析因、细节迁移、CLAHE 对比 | 探索性；受选模/阈值影响 |
| V2 | O/S/L/X/H/E | 统一全量源图 PNG | 100 epochs，seed 42；O/S 加 seed 2025 | 排除预处理混淆、匹配域重训 | 主分析 |
| V2.1 | 同上 + 交叉推理 | 同上 | 不新增训练 | NMS 完整性、last.pt 固定检查点、f_O/f_S 跨输入 | 最终收尾分析 |

**最终结论（以 V2.1 为准）**

1. **没有建立稳定的条件排序**。在固定 final-epoch 检查点下，O/S/L/X/H/E 的 AP50 为 0.478–0.491；H 最高（0.491），但相对 S（0.482）仅 +0.008，与 S 的 run-to-run 差异（0.482 / 0.491）同量级。不能说“S≈O”或“H 显著更优”。
2. **输入域偏移远大于条件内差异**。f_O(O)=0.490 → f_O(S)=0.219；f_S(S)=0.484 → f_S(O)=0.227；f_S(H)=0.458。匹配域训练是必要控制。
3. **H1a（硬截断）不成立/可忽略**：CCC 反推变换的潜在 R 截断 0.000%，官方 C 图 R≥254 仅 0.0003%。
4. **H1b 的“高频细节衰减”解释不成立**：自引导 GF 不是频率截止；仿射正偏移可在不模糊的情况下降低归一化对比度；一维明度映射 R²=0.710，但残差与色度相关。
5. **图像层明度分量主导 L\* 对比度**：G3 中 A=0.0746、M1=0.0282、M2=0.0742、M3=0.0282、C=0.0319；但检测端效应小且被运行差异覆盖。
6. **评估协议本身是结果的一部分**：作者仓库 `val.py` 默认 `conf_thres=0.2499`；NMS 超时会静默漏图；max_det 触顶常见。V2.1 已修复并量化其影响。

## 1. 研究问题与假设

- **RQ1（机制）**：全局色彩校正中，通道截断、明度变化、色度/色相偏移分别如何影响图像结构与检测？
- **RQ2（方法）**：能否在保持校准色度的同时，恢复诊断相关局部对比度并抑制不可靠区域放大？
- **RQ3（感知/显示）**：人眼与检测器对相同扰动的敏感度是否一致？观看条件如何影响？（未执行）

**假设与最终判读**

| 假设 | 最终判读 | 关键证据 |
|---|---|---|
| H1a 通道硬截断导致框膨胀/FP | **不成立/可忽略** | G1 潜在 R 截断 0.000%，实际 0.0003%；C≈M3 |
| H1b 多尺度明度细节衰减 | **机制表述需改写** | GF 非频率截止；仿射偏移即可降低归一化对比度；P0 扫描平坦 |
| H2 红色色度扩张独立增加 FP | **弱/部分支持** | V1 中 M2 的 FP 高于 M1；但单 seed、模型弱，V2 未稳定复现 |
| H3 人眼 vs 检测器 | **未执行** | 心理物理/观察者实验属于博士阶段 |
| 提出方法 H/P2 优于 E | **未建立** | V2.1 H 仅 +0.008 AP50，FP 更高；Holm 后不显著 |

## 3. 色彩变换与实验条件

### 3.1 V1：CCC 仿射反推

仓库不含 CCM 代码。用 10,922 对 OrigD↔CCCD 图在 gamma 空间拟合：

```
C = clip(M · A + b, 0, 255)
```

```
M = [[+0.2732, +0.3626, -0.0707],
     [-0.7361, +1.5802, -0.3176],
     [-0.5075, +0.1595, +0.8942]]
b = [+91.565, +73.629, +84.572]
```

- 分块均值 RMSE = **1.685/255**。
- 独立验证：与官方 CCC 图中位 ΔE00 = **0.76**，MAE≈2。
- 行和（含偏移/255）≈ [0.924, 0.815, 0.878]，均 <1：这是**降低对比度的仿射色调映射**，不是简单 CCM。

### 3.2 V2：只用 train split 重拟合

- 仅用 train split 的 O↔C_pub 对；块均值 RMSE = **1.455/255**。
- 验证 ΔE00：中位 **0.957**，P95 **1.193**。
- 负通道率 **0.0092%**，>255 率 **0.0000%**。
- 行和 ≈ [0.924, 0.814, 0.880]。
- **S 是“由图像对拟合的 CCC 渲染近似”，不是经物理测量验证的 PillCam SB3 标定**；Watine 的原始标定对象是 PillCam Colon2。

### 3.3 统一色域映射

对任意 (L,C,h)，若回转线性 sRGB 超出 [0,1]，固定 L 与 h，二分搜索最大色度缩放 s∈[0,1]。所有条件（A/M1/M2/M3/P0/P2/O/S/L/X/H/E）使用同一算子。色域映射会破坏理想的分量正交性，因此 V2 报告的是**实际输出条件**，不是理想 Lab 条件。

### 3.4 V1 条件（2×2 + 方法）

| 条件 | 明度 | 色度/色相 | 定义 |
|---|---|---|---|
| A | L0 | C0,h0 | 原始 |
| C | Lc（截断） | Cc,hc | 官方 8-bit CCC |
| M1 | Lc | C0,h0 | CCC 明度 + 原色度 |
| M2 | L0 | Cc,hc | 原明度 + CCC 色度 |
| M3 | Lc | Cc,hc | 无截断 CCC（C≈M3，未单独训练） |
| P0 | GF(Lc,r3)+D(L0,r3) | Cc,hc | 纯细节迁移 |
| P2 | GF(Lc,r3)+g·Q·D | Cc,hc | 提出方法 |
| E | CLAHE(C 的 L\*) | C 的色度 | CCC+CLAHE |
| D | CLAHE(A 的 L\*) | A 的色度 | 未训练（轻量方案） |

V1 参数：r3=64，r_med=16，e_clip=1.0；P2 初始按全黏膜 RMS 匹配 E 估计 **g≈5.26**，但实际生成 V1 P2 图时使用 **g=24** 才能在全局 RMS 上接近 E；后续 V2 的 H 改用有界 λ/η 参数化，避免这种极端细节增益。

> **公式修正**：V1 的“三尺度”细节为 D=(L0−G1)+(G1−G2)+(G2−G3)=**L0−G3**，代数上合并为单尺度残差。因此 V1 不能声称验证了“多尺度增强”的优越性；P1s 与 P2 的差异主要是分解半径，而不是独立尺度控制。V2 已放弃这条路线，改用有界 λ/η 联合控制。

### 3.5 V2 条件（统一源）

令 O 的 Lab 为 (L0,a0,b0)，S 的为 (Lc,ac,bc)：

```
I(λ,η) = G( (1-λ)Lc + λL0,
            (1-η)a0 + η ac,
            (1-η)b0 + η bc )
```

| 条件 | 含义 |
|---|---|
| O | 统一源原图 |
| S | 完整 CCC 渲染（λ=0, η=1） |
| L | 仅明度替换（λ=0, η=0） |
| X | 仅色度替换（λ=1, η=1） |
| H | 联合控制，**λ=0.25, η=1**（冻结） |
| E | S + CLAHE(L\*, clip=1.0) |

**H 选择**：200 张 val 图、15 点 (λ,η) 网格；约束 median ΔE00(S)≤2，最大化病灶框 Michelson。选中 H：ΔE00=1.652，局部 RMS=2.401（S=2.17），框 Michelson=0.0361（S=0.028），|ΔL|=1.77。  
> ΔE00≤2 是**探索性参考渲染偏差约束**，不是临床可接受阈值或真实组织色差。H 不再用检测器重新选择。

**判读**：p_clip ≪ 1%，按方案跳过 M3 独立训练；H1a 在本数据/本变换上不成立。

### 4.2 G2 等效亮度权重与梯度（V1）

- CCC 归一化等效权重：**[-0.942, 2.273, -0.331]**（原 luma [0.213, 0.715, 0.072]）。
- CC 权重：[-0.563, 1.780, -0.217]。
- 病灶框边界 G/L\* 梯度比：A **0.903** → C **0.893**（几乎不变）。
- 绝对梯度：G 0.0590→0.0415，L\* 0.0657→0.0470（同步下降约 30%）。

**判读**：不支持“红通道稀释绿色血红蛋白梯度”；对比度下降是全局性的。  
> gamma 空间的矩阵权重不是物理亮度权重；若要物理解释，应在线性 RGB 上计入解码函数导数，本报告不把 [-0.942,2.273,-0.331] 当作组织光学结论。

### 4.5 E2：方法性质验证（V2）

- **仿射偏移即可降低归一化对比度**：a=0.8,b=10 时，K'/K = 0.78–0.83，无需任何模糊。
- **自引导 GF 不是频率截止**：阶跃边缘对比度 0.3573→0.3572；正弦纹理 std 各周期约 4.9，而 σ=21 高斯在短周期降至 0.04–0.28。
- **一维明度映射**：137 张训练图，Lc≈0.391·L0+32.29，R²=0.710；低色度 R²=0.827，高色度 R²=0.708；残差 std=3.97，与色度相关 -0.550。

**判读**：一维明度映射是主导近似，但不完整；不能用“纯平滑明度压缩”解释全部变化，更不能证明检测副作用机制。

## 5. 检测训练配置

### 5.1 软硬件与兼容性

| 项 | 配置 |
|---|---|
| GPU | 本地 RTX 4060 Ti 16GB；远程 3×3090 + 2×3090 |
| Python / PyTorch | 本地 3.14.7 / 2.14.0+cu130；远程 3.12 / 2.4.1+cu121 |
| 检测器 | YOLOv5s（约 7.04M 参数，15.8 GFLOPs @576） |
| 图像 | 576×576 |
| 数据增强 | `hyp.controlled.yaml`：mosaic=0、mixup=0、hsv=0、flipud=0.5、fliplr=0.5、translate=0.1、scale=0.5 |

**YOLOv5 兼容补丁**

- `torch.load(..., weights_only=False)`。
- `np.trapz` → `np.trapezoid`；单类别 `np.atleast_1d`。
- 训练内验证 `save_txt=False, save_conf=False`。
- **NMS 完整性**：`time_limit = 0.5 + 0.05·batch` → `1e9`，避免超时后 `break` 留下空预测。

### 5.2 V1 训练

- Priority 0 锚点：官方 split + 官方增强（mosaic/HSV 开），20 epochs，seed 42。
- 受控：`A/C/M1/M2/P0/P2/E`，20 epochs，seed 42，关闭颜色增强与 mosaic。
- 结果：V1 仅作探索，不用于最终机制判断。

### 5.3 V2 训练

- 条件：O/S/L/X/H/E，100 epochs 名义预算，seed 42；O/S 额外 seed 2025。
- 实际完成轮数（提前停止）：O 92、S 90、L 99、X 93、H 97、E 93；O/S seed2025 均为 99。
- **检查点规则**：V2.1 主分析统一使用 `last.pt`（固定最终轮次），`best.pt` 仅作敏感性；实际轮数不同，因此不是严格同 epoch 比较。
- 没有周期性 checkpoint；无法做“共同 epoch”重选。后续若需严格同预算，应设置 `save_period` 或关闭早停。

### 6.3 V2.1 评估审计

- **阈值/选模**：`val.py` 默认 `conf_thres=0.2499`，训练内验证未覆盖；fitness=0.1·AP50+0.9·AP50-95，在 val 上选模。
- **NMS**：旧代码超时后 `break`；修复后 8 个主分析 `incomplete_batches=0`。
- **max_det 敏感性**：O last 在 300 vs 1000 下 AP50 **0.4783 vs 0.4776**，FP 均 894；触顶频繁但指标稳定，主表保留 300。
- **单元测试**：exact_single / wrong_class / duplicate_preds / gt_no_pred / pred_no_gt / empty 全部通过；AP 单例 0.995 为 101 点插值末端效应。
- **标签**：类别 0–11 均出现，坏标签 0，正常图非空标签 0，异常图空标签 0；类别 0=angiodysplasia。

### 6.6 冻结模型交叉推理（val）

| 输入条件 | f_O (O-trained) AP50 | f_S (S-trained) AP50 |
|---|---:|---:|
| O | 0.490 | 0.227 |
| S | 0.219 | 0.484 |
| L | 0.280 | 0.419 |
| X | 0.321 | 0.268 |
| H | 0.255 | 0.458 |
| E | 0.242 | 0.393 |

**判读**：

- f_O 在 O 上 0.490，换到 S 掉到 0.219；f_S 在 S 上 0.484，换到 O 掉到 0.227。**输入域偏移造成的下降远大于同域条件间 0.01 量级的差异**。
- H 更接近 S 域（f_S(H)=0.458，f_O(H)=0.255），说明联合控制本质上产生了一个新输入域；匹配域重训不是可选项。
- 这也解释了为什么“把校正图直接喂给原模型”或“把原图喂给校正模型”不能用来比较方法好坏：它们主要测的是域偏移。

## 7. 最终判读与对 RP 的影响

1. **删除“CCC 必然损害检测”的强因果表述**。V2.1 中 S 与 O 的 AP50 差异仅 +0.004，且未建立稳定排序；文献中的类别特异性 FP 变化仍需在更强模型/多种子下复核。
2. **删除“细节注入修复对比度”的强表述**。GF 不是频率截止；仿射偏移可在无模糊时降低归一化对比度；P0 平坦不能证明高频细节丢失。
3. **保留可测量事实**：明度分量主导 L\* 对比度变化；红色色度扩张对某些类别可能更敏感（V1 弱证据）；输入域偏移主导跨域检测。
4. **H 是保守工作点，不是已验证优胜方法**。H 的 AP50 仅 +0.008 vs S，FP/正常帧 FP 更高，Holm 不显著。
5. **评估协议必须写入论文**：低阈值推理、NMS 完整性、max_det 敏感性、正常帧 FP、检查点规则、run-to-run 差异、类别 FROC。
6. **RP 主线**：从“证明既定退化机制并修复”改为“建立可测量的色彩—明度—任务关系，并寻找适用条件”。WP1 测量与标定、WP2 受控干预、WP3 感知与显示。

### 建议的英文表述

> Under the current exploratory protocol, no robust performance ranking has been established between the original and transformed conditions. Checkpoint sensitivity and input-domain shift were substantial; matched-domain retraining is required to separate image effects from model adaptation. The pilot supports measurement-led development, not a claim of method superiority.

## 8. 局限性与未完成实验

- **训练预算不完全一致**：V2 last.pt 实际完成 90–99 epochs（提前停止），不是严格同 epoch；没有周期性 checkpoint。
- **单/双 seed**：只有 O/S 有两个运行；H/E 仍单 seed。不能做跨 seed 聚合或稳健方差估计。
- **检测器单一**：仅 YOLOv5s；RetinaNet、其他 YOLO 变体未跑。
- **H 选择**：图像层约束选择，未完成冻结检测器 15 点网格推理；ΔE00≤2 只是探索性参考渲染约束。
- **未完成**：H/E seed 2025、O/S/H/E seed 3407、Kvasir-Capsule 外部验证、观察者实验、视频时序稳定性、显示条件（SO7）。
- **数据独立性**：感知哈希簇不是患者 ID；test 已被探索使用，不能称为确认性测试集。
- **S 的身份**：图像对拟合的 CCC 渲染近似，不是物理标定的 SB3 色彩真值。

## 11. 一句话总结

**V1 建立了析因与图像层分析，但 20-epoch、单 seed、阈值/NMS 问题使其不足以证明机制；V2/V2.1 用统一源、100-epoch 匹配域训练和完整评估纠正了这些偏差，最终结论是：没有稳定的方法排序，输入域偏移远大于条件差异，H 只是一个保守的联合控制工作点，而不是已验证的优胜方法。**
