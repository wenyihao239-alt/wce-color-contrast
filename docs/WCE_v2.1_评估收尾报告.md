# WCE V2.1：评估收尾、固定检查点重评与冻结模型交叉推理

**日期**：2026-11-04  
**本地**：RTX 4060 Ti 16GB；**远程**：192.168.10.3（3×3090）+ 192.168.10.65（2×3090）  
**范围**：这是申请前的探索性技术收尾，不是验证性研究；H 参数已冻结，不再根据测试结果改选。

## 0. 结论

- **未建立稳定的条件排序**。在固定的 final-epoch 检查点下，O/S/L/X/H/E 的 AP50 为 0.478–0.491；H 最高（0.491），但相对 S（0.482）仅 +0.008，与 S 的 run-to-run 差异（0.482 / 0.491）同量级。
- **不能称为“等价”**。Holm 检验主要针对 FP 计数，不能用于判定 AP 等价；正确表述是“当前协议下未观察到稳健的性能差异”。
- **检查点敏感但原因未完全分离**：`best.pt` 与 `last.pt` 的测试 AP50 差异明显；由于选模 fitness 是 0.1·AP50 + 0.9·AP50-95、且验证/测试不同，不能把差异单独归因于 0.2499 阈值。`last.pt` 只应称为“固定最终轮次检查点”，不是“无偏”。
- **NMS 完整性已修复**：把 `time_limit` 置为无穷大后，8 个主分析的 `incomplete_batches` 均为 0。max_det 触顶仍频繁，但对 O 的 300 vs 1000 敏感性测试显示 AP50 仅变化 0.0007、FP 不变。
- **输入域偏移远大于条件内差异**：f_O(O)=0.491 → f_O(S)=0.219；f_S(S)=0.484 → f_S(O)=0.227；f_S(H)=0.458。冻结模型跨域推理出现灾难性下降，说明“匹配域训练”是必要控制，而不是可选细节。
- **H 仍是保守工作点，不是已验证的优胜方法**。

## 1. E0：评估与选模审计

- `val.py` 默认 `conf_thres=0.2499`，训练内 `validate.run()` 未覆盖；选模 fitness 为 0.1·AP50 + 0.9·AP50-95，且在验证集上计算。
- v1 的 best/last 低阈值重评显示：A 0.268→0.310、C 0.251→0.292、M1 0.291→0.276、M2 0.290→0.312、P0 0.282→0.282、P2 0.283→0.283、E 0.276→0.305。
- **NMS 修复**：仓库在 `time_limit = 0.5 + 0.05·batch` 超时后 `break`，未处理图像保留空预测。已改为 `1e9`；重评后所有主分析 `incomplete_batches=0`。
- **max_det 敏感性**：O last 在 max_det=300 时 AP50=0.4783、FP=894；max_det=1000 时 AP50=0.4776、FP=894。触顶频繁但指标稳定，主表保留 300。
- 单元测试：exact_single / wrong_class / duplicate_preds / gt_no_pred / pred_no_gt / empty 全部通过；AP 单例为 0.995 是 101 点插值末端效应，需用固定参考实现对照，不能笼统解释。
- 标签审计：类别 0–11 均出现，坏标签 0，正常图非空标签 0，异常图空标签 0；类别 0 = angiodysplasia。

## 2. E1：统一条件与 CCM v2

- 仅在 train split 的 O↔C_pub 对上重拟合；块均值 RMSE=1.455/255；val 中位 ΔE00=0.957，P95=1.193。
- 负通道率 0.0092%，>255 率 0.0000%。
- 所有条件由同一全量 SEE-AI 源图生成（异常/正常同路径，PNG），S 仅为“由图像对拟合的 CCC 渲染近似”，不是经物理测量验证的 SB3 标定。

## 3. E2：方法性质

- 仿射偏移 (a=.8,b=10) 使归一化 Michelson 对比度降至输入的 0.78–0.83，**无需任何模糊**。
- 自引导 GF(r=64) 对阶跃边缘的对比度 0.3573→0.3572，几乎不变；正弦纹理 std 在各周期约 4.9，而 σ=21 高斯在短周期降至 0.04–0.28。**GF 不是频率截止**。
- Lc≈a·L0+b：a=0.391，R²=0.710；低色度 R²=0.827，高色度 R²=0.708；残差 std=3.97，与色度相关 -0.550。一维明度映射是主导近似，但不完整。

## 4. E3：H 的固定

H=(λ=0.25, η=1.0)，由 200 张 val 图的 15 点网格选出；约束 median ΔE00(S)≤2，最大化病灶框 Michelson。
选中点：ΔE00(S)=1.652，局部 RMS=2.401（S=2.17），框 Michelson=0.0361（S=0.028）。
> ΔE00≤2 是探索性参考渲染偏差约束，不是临床可接受阈值或真实组织色差；H 不再根据检测器重新选择。

## 6. E5：冻结模型交叉推理（val）

| 输入条件 | f_O (O-trained) | f_S (S-trained) |
|---|---|---|
| O 原图 | 0.490 | 0.227 |
| S CCC 渲染 | 0.219 | 0.484 |
| L 仅明度 | 0.280 | 0.419 |
| X 仅色度 | 0.321 | 0.268 |
| H 联合控制 | 0.255 | 0.457 |
| E S+CLAHE | 0.242 | 0.393 |

**解读**：f_O 在 O 上 0.491，换到 S 掉到 0.219；f_S 在 S 上 0.484，换到 O 掉到 0.227。输入域偏移造成的下降远大于同域条件间 0.01 量级的差异。H 更接近 S 域（f_S(H)=0.458，f_O(H)=0.255），说明联合控制本质上仍是一个新的输入域；匹配域重训不可省略。

## 8. 对申请版 RP 的写法约束

1. 写“under the current exploratory protocol, no robust performance ranking has been established”，不要写“S≈O”或“H 无效”。
2. 写“fixed final-epoch checkpoint”，不要写“unbiased”；best/last 差异仅作为检查点敏感性证据。
3. 写“run-to-run differences”，不要写“seed variance”后直接外推到其他条件。
4. H 的 ΔE00≤2 称为“exploratory reference-rendering constraint”，不是临床容差。
5. 先导工作只声称：统一数据/变换/评估管线、分量干预、匹配域训练、冻结模型交叉推理；不声称方法优越或机制已证。
6. NMS 完整性、max_det 敏感性、正常帧 FP 必须写进评估协议。
